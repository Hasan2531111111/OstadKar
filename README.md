# استاد کار (OstadKar)

اپلیکیشن اندروید حرفه‌ای مدیریت پروژه‌های ساختمانی (کاشی‌کاری، سرامیک، سنگ نما و ...)

## تکنولوژی‌ها

- Kotlin
- Jetpack Compose + Material 3
- Clean Architecture + MVVM
- Room Database (کاملاً Offline)
- Hilt
- Navigation Compose
- Kotlin Coroutines + Flow / StateFlow
- RTL و فارسی کامل

## نحوه اجرا

1. پوشه `OstadKar` را با **Android Studio** (Hedgehog یا جدیدتر) باز کنید.
2. Gradle Sync (اینترنت برای وابستگی‌ها لازم است).
3. Emulator یا دستگاه API 26+ انتخاب و Run کنید.

در اولین اجرا انواع کار پیش‌فرض و زیرمجموعه‌ها seed می‌شوند.

## جریان کاربری اصلی

1. **کار جدید** → نام مشتری، موبایل، آدرس
2. ورود به جزئیات پروژه → داشبورد مالی
3. **آیتم‌های کار** → انتخاب نوع کار / محل / متراژ / قیمت واحد
4. **پرداخت مشتری** → چند قسط با روش پرداخت
5. **کارگران** → افزودن نفر، ثبت کارکرد، پرداخت دستمزد
6. **مراحل کار** → تغییر وضعیت با لمس
7. **هزینه‌ها** → مصالح و سایر

## ساختار پکیج

```
com.ostadkar.app/
├── data/local|mapper|repository
├── di/
├── domain/model|repository|usecase
└── presentation/ui|viewmodel
```

همه محاسبات (متراژ، قیمت، دستمزد، سود) در `domain/usecase` هستند.
